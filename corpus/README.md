# Corpus

This directory holds redcell's **probe cases** — the defensive benchmark of
behaviors an agent should resist, organized by OWASP Top 10 for Agentic
Applications (2026) category.

It is intentionally **empty for now**. Cases are data, loaded and validated by
`redcell.corpus_loader`, and are added in a later phase. Nothing here is an
exploit or an attack payload; each case describes a behavior to *test for* so
you can confirm your own agent handles it safely.

> ETHICS / SCOPE: For authorized testing of systems you own or are permitted to test.
