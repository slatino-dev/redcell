# Targets

Placeholder for an **in-repo, deliberately-simple demo target** — a small,
purpose-built agent used only to validate that the harness wiring works
end-to-end (corpus -> adapter -> oracle -> report). It exists so contributors
can run redcell without pointing it at a real system.

Empty for now; the demo target lands in a later phase and will be driven by the
`DemoAdapter` in `redcell.adapters`.

> ETHICS / SCOPE: For authorized testing of systems you own or are permitted to test.
